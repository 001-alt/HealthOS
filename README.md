# HealthOS 项目说明

## 项目简介

HealthOS 是一款基于 Expo + React Native 构建的个人健康管理应用，定位为“你的个人 AI 健康操作系统”。它将身体数据、日常习惯、饮食记录、训练计划和 AI 建议集中在一个移动端工作空间中，帮助用户持续记录变化，并把健康目标拆解为可执行的每日行动。

HealthOS 只提供生活方式与健康管理建议，不能替代医生诊断、治疗或专业营养指导。

## 核心功能

### 1. 个人健康档案

- 首次使用时记录年龄、性别、身高、体重、腰围、活动水平和健康目标。
- 支持健康匀称、精瘦、腹肌明显、增肌和降低体脂等目标。
- 支持补充胸围、臀围、手臂围和体脂率等身体指标。
- 可设置体重和腰围目标，并查看目标进度。

### 2. 身体变化记录

- 按日期记录体重、腰围和体脂率。
- 通过趋势图查看身体数据的历史变化。
- 显示最新数值、首末记录差值和最近记录列表。
- 对输入数据进行范围校验，减少异常数据对趋势判断的影响。

### 3. 每日健康打卡

- 记录饮水量、步数和睡眠时长。
- 通过进度卡片查看每日习惯完成情况。
- 首页集中展示体重、饮水、训练、睡眠和蛋白质等关键指标。

### 4. 饮食与蛋白质记录

- 按日期记录实际吃过的食物和对应蛋白质摄入量。
- 根据个人档案和健康目标计算每日蛋白质目标。
- 展示当日蛋白质累计摄入、目标进度和已记录食物数量。
- 明确区分 AI 推荐菜单与用户实际摄入，避免将建议误认为真实记录。

### 5. 训练计划与完成记录

- 查看按日期组织的训练计划。
- 支持系统模板、AI 建议和用户自定义三类训练来源。
- 可编辑训练名称、动作、组数、次数或时长。
- 单独记录实际完成动作、训练时长和训练感受。
- 对疼痛、不适、未来日期和重复记录等情况进行保护性校验。

### 6. AI 健康教练

- 支持配置用户自己的 DeepSeek API Key。
- 根据身体档案、饮食、睡眠、饮水、步数和训练记录生成每日建议。
- 输出今日概况、行动清单、饮食安排、可选训练和恢复建议。
- 支持填写当天的时间安排、饮食禁忌、器械条件和训练反馈。
- AI 建议强调保守、可执行和非医疗化，不生成极端节食或强制训练方案。

### 7. 身体照片

- 可选择并保存身体照片，用于个人前后对比。
- 照片保存在本机，不会作为 AI 提示内容发送给 DeepSeek。

## 技术栈

- Expo 57
- React 19
- React Native 0.86
- TypeScript 6
- `expo-sqlite`：保存本地健康档案、身体记录、每日打卡、饮食和训练数据
- `expo-secure-store`：保存 DeepSeek API Key
- `expo-image-picker`：选择身体照片
- `react-native-svg`：绘制身体数据趋势图
- DeepSeek Chat API：生成个性化健康建议和训练草稿

## 数据与隐私

- 健康档案、身体记录、饮食记录和训练记录默认保存在设备本地 SQLite 数据库中。
- DeepSeek API Key 使用系统安全存储保存，不写入普通文本配置文件。
- 身体照片保存在本机，不会放入 AI 请求内容。
- 只有在用户主动生成 AI 建议时，相关健康记录和输入偏好才会发送给 DeepSeek API。
- 应用提供本地数据重置功能；重置会删除本机保存的档案、记录和每日打卡，且无法撤销。


## 本地运行

### 环境要求

- Node.js
- npm
- Expo CLI 所需的运行环境
- Android Studio（运行 Android 原生版本时需要）
- Xcode（运行 iOS 原生版本时需要，仅 macOS）

### 安装依赖

```bash
npm install
```

### 启动开发服务

```bash
npm run start
```

### 运行平台

```bash
# Android
npm run android

# iOS
npm run ios

# Web
npm run web
```

### 代码检查

```bash
npm run lint
```

## 使用建议

1. 首次打开应用时完成个人档案和健康目标设置。
2. 持续记录体重、腰围、睡眠、饮水、步数、饮食和训练完成情况。
3. 在“我的”中配置自己的 DeepSeek API Key 后使用 AI 教练功能。
4. 将 AI 输出视为辅助建议，结合自身实际情况判断；如有疼痛、疾病或持续不适，应停止相关活动并咨询专业人士。

## 项目状态

当前版本为 `1.0.0`，主要面向个人本地健康记录和 AI 辅助计划管理。项目暂未包含云端账号体系、跨设备同步或医疗机构数据对接功能。
